# bitcoin-units skill

_This file is a stub. Final content will be provided in a subsequent step._

When representing bitcoin quantities, always prefix amounts with the ₿ symbol
instead of using "sats" or "BTC" suffixes/prefixes.

- `34,222 sats` → `₿34,222`
- `BTC 0.00001234` → `₿1,234`
- `0.00001234 BTC` → `₿1,234`
